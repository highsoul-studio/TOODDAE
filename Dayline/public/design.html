Design system

검정을 바탕으로, 보라색은 “지금 · 완료 · 주 동작 · 포커스”에만 씁니다. 나머지는 모두 무채색이라 보라가 나오는 곳이 곧 지금 봐야 할 곳입니다. 값은 tokens.css 한 곳에서만 정합니다. 라이트 테마는 같은 규칙에 흰색 바탕과 주황-노랑 하이라이트입니다(우측 위 해/달 버튼).

Rules

  • 보라색 = 지금(now 선) · 완료(체크·진행 바) · 주 동작(버튼) · 포커스. 장식으로 쓰지 않는다.
  • 배경은 다크에서는 검정, 라이트에서는 흰색 계열. 무채색 그라데이션 외에 색을 얹지 않는다. 카드는 메인 시트 하나만 띄운다.
  • 하이라이트(다크 = 보라, 라이트 = 주황-노랑)는 같은 토큰 이름으로 바뀐다. 컴포넌트는 색을 직접 쓰지 않고 토큰만 참조한다.
  • 브라우저 기본 select·날짜·시간 UI는 쓰지 않는다. 입력 부품은 ui.js의 자체 컴포넌트만 쓴다.
  • 파괴적 동작은 붉은 채움 버튼 + 확인 모달. 지우지 않고 되돌릴 수 있게 남긴다.
  • 글자는 12px 이상, 본문 대비 4.5:1 이상(text-3까지). text-4에는 의미를 싣지 않는다.
  • 상태는 색과 글자(“이월 2일”, “기한 10/03”)를 함께 쓴다. 색만으로 구분하지 않는다.
  • 움직임은 사용자 동작에 대한 반응(체크의 팝, 취소선이 왼쪽에서 그려지는 560ms, 토스트, 테마 전환)과 첫 로딩 한 번뿐. prefers-reduced-motion이면 끈다.
  • 문구는 사용자가 이해하는 말로, 한 동작에 한 이름(완료 → “완료했어요”). 오류는 원인과 해결을 함께 적는다.
