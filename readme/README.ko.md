# TOODDAE

### 하루에 조금 더 여유를.

할 일, 시간, 노트를 내가 관리하는 폴더에.

[시작하기](#시작하기) · [이런 것들을 할 수 있습니다](#이런-것들을-할-수-있습니다) · [내 파일](#내-파일은-내가-관리합니다)

![Day line, 오늘 할 일, 루틴, 다가오는 일정을 함께 보여 주는 TOODDAE 다크 모드 화면.](../docs/assets/readme/do-overview.png)

</div>

**TOODDAE는 계획하고, 실행하고, 기억하기 위한 로컬 우선 개인 작업 공간입니다.** 할 일을 하루의 시간에 배치하고, 루틴을 가까이 두고, 그 주변의 생각을 일반 Markdown 파일로 남겨 보세요.

[한국어](README.ko.md) · [日本語](README.ja.md) · [English](../README.md) · [简体中文](README.zh.md)

> 아래 이미지는 영어 인터페이스에 가상의 데모 데이터를 넣어 촬영한 실제 앱 화면입니다. AI 비교 화면은 검토와 적용 과정을 보여 주기 위한 로컬 예시 응답이며, 실제 모델의 실행 결과가 아닙니다. 새 작업 공간에는 이 예시 기록이 포함되지 않습니다.

## 🧭 이런 것들을 할 수 있습니다

<a id="오늘에-집중하면서-다음-일도-놓치지-않기"></a>

### 📅 오늘에 집중하면서, 다음 일도 놓치지 않기

**Do** 페이지에서는 일상에 필요한 네 가지 보기를 함께 볼 수 있습니다.

- **오늘 할 일:** 섹션별로 일을 나누고, 우선순위와 짧은 메모를 추가하고, 끝낸 일을 체크하세요.
- **루틴:** 반복하는 습관을 오늘의 할 일과 함께 관리하세요. 시간과 반복 규칙도 따로 지정할 수 있습니다.
- **다가오는 일정:** 날짜가 정해진 일을 오늘의 할 일이 되기 전에 확인하세요.
- **인박스:** 언제 할지 아직 정하지 않은 일과 아이디어를 먼저 모아 두세요.

**Day line**은 시간이 지정된 할 일과 루틴을 같은 하루 타임라인에 보여 줍니다. 시작 시각, 시간 범위, 또는 `〜17:00 제안서 보내기`처럼 종료 시각만 있는 마감을 사용할 수 있습니다.

### 📝 흩어진 메모를 나만의 노트 라이브러리로

**Write**에는 회의 메모, 아이디어, 독서 기록, 회고를 남길 수 있습니다. 같은 날짜에 여러 노트를 만들고, 제목과 본문 전체를 검색하고, 편집 화면과 읽기 편한 Markdown 미리보기를 오가세요.

![왼쪽에는 검색 가능한 노트 목록, 오른쪽에는 제목·목록·표·인용문으로 작성한 주간 계획이 있는 Write 라이브러리.](../docs/assets/readme/write-library.png)

- 노트에 제목을 붙이고, 자세한 내용은 본문에 남기세요.
- 제목, 목록, 링크, 표를 활용해 작성하세요.
- 편집 내용은 자동 저장됩니다. **저장**을 누르면 읽기 화면으로 돌아갑니다.
- 이전 버전을 복구하고, 지원되는 노트 삭제 작업을 되돌릴 수 있습니다.

### ✨ 거친 메모를 활용하기 좋은 기록으로

**AI로 정리**는 선택한 노트를 더 읽기 쉽게 정리한 내용을 제안합니다. <em>“결정한 것, 다음 할 일, 나중에 검토할 것을 나눠 주세요.”</em>처럼 추가 지시를 적어 보세요. 원문과 제안을 나란히 검토한 뒤, 저장하고 싶을 때 **AI 제안 적용**을 선택하면 됩니다.

![왼쪽의 회의 메모 원문과 오른쪽의 결정 사항·다음 행동 제안, 아래의 AI 제안 적용 버튼을 보여 주는 비교 화면.](../docs/assets/readme/ai-organize.png)

**적용 여부는 내가 결정합니다.** 정리 요청을 직접 실행하고, 전송 대상에 동의하고, 연결 테스트를 통과한 경우에만 선택한 노트가 전송됩니다. 제안을 생성하는 것만으로 원문을 덮어쓰지 않습니다. 모델의 결과에는 오류가 있을 수 있으니 적용 전에 검토하세요.

Do 페이지에는 지원되는 할 일·루틴·섹션 작업을 자연어로 요청하는 제한된 범위의 도우미도 있습니다. Write의 노트 정리와는 별도 기능입니다. [AI 도구와 한계](../docs/AI-TOOLS-AND-SKILLS.md)를 참고하세요.

## 🚀 시작하기

**필요한 환경:** Node.js **20 이상**과 브라우저. 앱 실행에 필요한 **npm 의존성은 없습니다.** 실행을 위해 `npm install`을 할 필요가 없습니다.

저장소를 복제하거나, 소스를 내려받아 압축을 푸세요.

```bash
git clone https://github.com/highsoul-studio/TOODDAE.git
cd TOODDAE
node scripts/start-demo.mjs
```

[**http://127.0.0.1:44318**](http://127.0.0.1:44318)을 여세요. 온라인으로 호스팅된 웹사이트가 아니라 내 컴퓨터에서 실행되는 앱입니다. 터미널에서 **Ctrl+C**를 누르면 종료됩니다.

첫 실행 시 시작 스크립트는 `runtime/default/`에 노트 폴더를 만들고, `runtime/demo-home/`에 기기 설정을 보관합니다. 기존 노트를 자동으로 연결하거나 로그인 시 실행 서비스를 설치하지 않습니다. 나중에 직접 선택한 폴더는 기억됩니다. 기존 노트를 연결하기 전에는 먼저 백업하세요.

<details open>
<summary>🍎 macOS: 일반 앱처럼 TOODDAE 열기</summary>

저장소의 최상위 폴더에서 실행하세요.

```bash
cd Dayline
npm run app:package
```

Finder에서 저장소 최상위에 생성된 **TOODDAE.app**을 여세요. 일치하는 로컬 백그라운드 서버를 시작하거나 재사용하고, 브라우저를 엽니다. 진짜 앱처럼 쓰려면 **TOODDAE.app**을 **응용 프로그램** 폴더로 끌어다 놓고 Launchpad나 Spotlight에서 여세요. 생성할 때 기록한 이 저장소 폴더와 Node.js를 계속 사용하므로 두 위치는 그대로 두세요.

로컬 실행을 편리하게 하는 아이콘이며, **독립 실행형 설치 파일은 아닙니다.** Node.js를 포함하지 않고 LaunchAgent나 로그인 항목을 설치하지 않습니다. 생성 시 기록한 Node.js와 작업 폴더 경로가 필요하므로, 둘 중 하나를 옮기면 다시 생성하세요. macOS 전용입니다.

생성된 앱은 로컬 사용을 위한 ad-hoc 서명만 되어 있고 Apple 공증은 받지 않았습니다. 처음 열 때 "Apple이 악성 코드가 없는지 확인할 수 없음" 경고가 뜨면, Finder에서 앱을 우클릭한 뒤 **열기**를 선택하거나 시스템 설정 → 개인정보 보호 및 보안에서 **그래도 열기**로 허용하세요.

**다시 열어도 안전합니다.** 브라우저 탭을 닫아도 백그라운드 서버는 계속 실행됩니다. **TOODDAE.app**을 다시 열면 그 서버를 그대로 재사용하며 "포트가 사용 중" 메시지는 뜨지 않습니다. 이 메시지는 *다른* 사본이나 버전의 TOODDAE가 44318 포트에서 아직 실행 중일 때만 나타납니다. 그 경우 먼저 해당 프로세스를 종료한 뒤(활동 상태 보기에서 `node` 검색, 또는 메시지에 표시된 PID로 `kill <PID>` 실행) 앱을 다시 여세요. 백그라운드 서버를 직접 끄려면 `lsof -ti tcp:44318 -sTCP:LISTEN | xargs kill`을 실행하세요. 앱의 서버가 실행 중일 때 `node scripts/start-demo.mjs`를 함께 실행하지 마세요. 둘 다 44318 포트를 씁니다.

</details>

<a id="선택-사항-ai-연결"></a>

### 🔌 선택 사항: AI 연결

기본적인 할 일 관리와 글쓰기는 AI나 클라우드 계정 없이 사용할 수 있습니다.

AI 도움을 받으려면 **Set**에서 제공자와 모델을 선택하고, 연결을 설정하고, 해당 전송 대상에 동의한 다음 **AI 연결 테스트**를 실행하세요. API 키 방식은 **OpenAI, Anthropic, Gemini, DeepSeek**를 지원합니다. 제공자 이용 요금이 발생할 수 있습니다.

선택 사항으로 ChatGPT 로그인과 Claude Code 구독 연결 기능도 포함되어 있습니다. 다만 사용 가능 여부는 계정과 지원되는 로컬 실행 환경에 따라 달라집니다. 기능이 포함되어 있다는 것만으로 이용 자격이나 실제 계정과의 호환성이 보장되지는 않습니다. API 키와 구독 자격 증명은 노트 폴더 밖에 보관합니다.

설정 범위와 검증 내용은 [구현 상태](../docs/IMPLEMENTATION-STATUS.md)를 참고하세요.

## 📁 내 파일은 내가 관리합니다

TOODDAE는 폴더에 있는 Markdown 파일을 읽고 씁니다.

```text
노트 폴더/
├── Daily/              일일 할 일과 해당 날짜의 루틴
├── Templates/          앞으로 적용할 루틴 정의
├── Write/              날짜별 여러 노트를 포함한 기록
├── Inbox.md            날짜가 없는 할 일
└── Set/                작업 공간 설정
```

- **로컬 우선:** 내 컴퓨터에서 앱을 실행하고, 사용할 폴더를 직접 선택하세요.
- **일반 Markdown:** Obsidian이나 다른 Markdown 편집기에서 파일을 읽고 수정하세요. Obsidian 플러그인은 필요하지 않습니다.
- **양방향 편집:** 앱에서 수정한 내용과 연결된 파일에서 직접 편집한 내용은 같은 데이터에 반영됩니다.
- **선택적 외부 AI:** 로컬 저장이 로컬 AI 실행을 뜻하지는 않습니다. AI 요청을 직접 실행하면 허용된 맥락이 선택한 연결 대상으로 전송됩니다.

컴퓨터에 연결된 동기화 폴더에 노트를 저장할 수는 있지만, 이것만으로 TOODDAE가 호스팅 서비스가 되거나 휴대폰에서 실행되는 것은 아닙니다. 기본 제공 서버는 로컬 루프백 주소로 접근합니다.

## 🛠️ 프로젝트 상태와 개발
