# TOODDAE

### 给每一天，多留一点余地。

任务、时间和笔记，都放在你自己管理的文件夹里。

[开始使用](#开始使用) · [你可以做什么](#你可以做什么) · [你的文件](#文件由你掌控)

![TOODDAE 深色模式：在同一页面显示 Day line、今日任务、例行事项和即将到来的安排。](../docs/assets/readme/do-overview.png)

</div>

**TOODDAE 是一个用于计划、执行和记录的本地优先个人工作空间。** 为任务安排一天中的时间，把例行事项放在身边，并将相关的想法保存为普通 Markdown 文件。

## 🧭 你可以做什么

<a id="专注今天也不错过接下来的安排"></a>

### 📅 专注今天，也不错过接下来的安排

**Do** 页面汇集了四种日常视图。

- **今日任务：** 按分区组织工作，添加优先级和简短备注，并勾选已完成的事项。
- **例行事项：** 将重复的习惯与今天的工作放在一起管理，也可以分别设置时间和重复规则。
- **即将到来：** 在有日期的任务成为今天的工作之前，提前查看它们。
- **收件箱：** 先收集想法和没有日期的任务，不必立即决定何时处理。

**Day line** 将有指定时间的任务和例行事项放在同一条每日时间轴上。可以使用开始时间、时间范围，或 `〜17:00 发送提案` 这样的仅有结束时间的截止安排。

<a id="看见每一天的积累"></a>

### 📈 看见每一天的积累

通过**最近 12 周**的网格查看每日完成程度，并了解今天的进度。连续每天完成所有计入目标的事项，就能延续连续记录。截止日期在未来的任务不会计入今天的主要完成目标。

<img src="../docs/assets/readme/history.png" alt="最近 12 周的活动网格，显示不同日期的完成程度以及由少到多的图例。" width="364">

<a id="把零散笔记整理成自己的资料库"></a>

### 📝 把零散笔记整理成自己的资料库

**Write** 可用于会议笔记、想法、阅读记录和复盘。你可以在同一天创建多篇笔记，搜索标题与全文，并在编辑界面和易于阅读的 Markdown 预览之间切换。

![Write 笔记库：左侧是可搜索的笔记列表，右侧是包含标题、列表、表格和引用的一周计划。](../docs/assets/readme/write-library.png)

- 为每篇笔记添加标题，把详细内容写在正文中。
- 使用标题、列表、链接和表格记录内容。
- 编辑内容会自动保存，也可以选择**保存**返回阅读界面。
- 恢复早期版本，并撤销支持恢复的笔记删除操作。

<a id="把粗略笔记变成可用的记录"></a>

### ✨ 把粗略笔记变成可用的记录

**用 AI 整理**会为选中的笔记提出一个更清晰的版本。你可以添加指示，例如<em>“请分别列出决定、下一步行动和以后再考虑的事项”</em>。并排审阅原文与建议，然后在想要保存时选择**应用 AI 建议**。

![AI 整理对比：左侧是原始会议笔记，右侧是决定与下一步行动的建议，下方有明确的应用 AI 建议按钮。](../docs/assets/readme/ai-organize.png)

**是否应用，由你决定。** 只有在你明确提交整理请求、同意向该目标发送内容并通过连接测试后，选中的笔记才会被发送。生成建议本身不会覆盖原文。模型的结果可能有误，请先审阅再应用。

Do 页面还提供范围受限的自然语言助手，用于支持的任务、例行事项和分区操作。它与 Write 的笔记整理流程是两项独立功能。详见 [AI 工具与限制](../docs/AI-TOOLS-AND-SKILLS.md)。

<a id="开始使用"></a>

## 🚀 开始使用

**运行要求：** Node.js **20 或更高版本**和浏览器。应用**没有运行时 npm 依赖包**，启动前无需执行 `npm install`。

克隆仓库，或下载并解压源代码。

```bash
git clone https://github.com/highsoul-studio/TOODDAE.git
cd TOODDAE
node scripts/start-demo.mjs
```

打开 **[http://127.0.0.1:44318](http://127.0.0.1:44318)**。这是运行在你自己电脑上的应用，不是托管网站。在终端中按 **Ctrl+C** 即可停止。

首次运行时，启动脚本会在 `runtime/default/` 创建笔记文件夹，并在 `runtime/demo-home/` 保存设备设置。它不会自动连接现有笔记，也不会安装登录时启动的服务。以后由你主动选择的文件夹会被记住。连接已有笔记前，请先备份。

<details open>
<summary>🍎 macOS：像普通应用一样打开 TOODDAE</summary>

从仓库根目录运行：

```bash
cd Dayline
npm run app:package
```

在 Finder 中打开仓库根目录下生成的 **TOODDAE.app**。它会启动或复用匹配的本地后台服务器，并打开浏览器。 想像真正的应用一样使用，请把 **TOODDAE.app** 拖进“应用程序”文件夹，然后从启动台或聚焦搜索打开。它仍会使用生成时记录的此仓库文件夹和 Node.js，请不要移动这两者。

这是方便本地启动的工具，**不是独立安装包**。它不包含 Node.js，也不安装 LaunchAgent 或登录项。它依赖生成时记录的 Node.js 和工作目录路径；移动其中任何一项后，请重新生成。此启动器仅适用于 macOS。

生成的应用仅做了供本地使用的 ad-hoc 签名，未经过 Apple 公证。首次打开时如果出现“Apple 无法验证…不含恶意软件”的警告，请在 Finder 中右键点击该应用并选择**打开**，或在“系统设置 → 隐私与安全性”中点击**仍要打开**。

**再次打开是安全的。** 关闭浏览器标签页不会停止后台服务器。再次打开 **TOODDAE.app** 只会复用该服务器，不会出现“端口已被占用”的提示。只有当*另一个*副本或版本的 TOODDAE 仍在 44318 端口运行时才会出现该提示。此时请先退出那个进程（在“活动监视器”中搜索 `node`，或使用提示中显示的 PID 运行 `kill <PID>`），然后再次打开应用。如需自行停止后台服务器，请运行 `lsof -ti tcp:44318 -sTCP:LISTEN | xargs kill`。应用的服务器运行期间，请不要同时运行 `node scripts/start-demo.mjs`，两者都使用 44318 端口。

</details>

<a id="可选连接-ai"></a>

### 🔌 可选：连接 AI

基本的任务管理和写作不需要 AI 或云账号。

如需 AI 辅助，请在 **Set** 中选择提供商和模型，配置连接，同意向该目标发送内容，然后运行**测试 AI 连接**。API 密钥方式支持 **OpenAI、Anthropic、Gemini 和 DeepSeek**。使用提供商的服务可能产生费用。

还包含可选的 ChatGPT 登录和 Claude Code 订阅连接功能，但是否可用取决于账号和受支持的本地运行环境。包含这些功能并不保证使用资格或真实账号的兼容性。API 密钥和订阅凭据保存在笔记文件夹之外。

设置范围与验证详情请参阅[实现状态](../docs/IMPLEMENTATION-STATUS.md)。

## 📁 文件由你掌控

TOODDAE 读取和写入文件夹中的 Markdown 文件。

```text
笔记文件夹/
├── Daily/              每日任务和当天的例行事项
├── Templates/          未来日期使用的例行事项定义
├── Write/              笔记，支持同一天的多篇记录
├── Inbox.md            没有日期的任务
└── Set/                工作空间设置
```

- **本地优先：** 在自己的电脑上运行应用，并选择它使用的文件夹。
- **普通 Markdown：** 可以在 Obsidian 或其他 Markdown 编辑器中阅读和编辑文件，无需 Obsidian 插件。
- **双向编辑：** 应用中的更改和对已连接文件的编辑使用同一份数据。
- **可选的外部 AI：** 本地存储不等于本地推理。主动提交 AI 请求时，获准使用的上下文会发送到你选择的连接目标。

连接到电脑的同步文件夹可以存储笔记，但不会因此把 TOODDAE 变成托管服务，也不会提供手机运行环境。默认提供的服务器使用本地环回访问。

## 🛠️ 项目状态与开发

可运行的应用位于 `Dayline/`，这一目录名沿用了最初的原型。**主要开发环境是 macOS。** 浏览器测试包含 Chromium 和移动屏幕尺寸模拟；真实手机、其他浏览器引擎以及 Windows/Linux 的原生安装尚未验证。

运行单元测试和本地 HTTP 测试：

```bash
cd Dayline
npm test
```

Playwright 验证使用单独的开发测试工作区，需要其自身的依赖包和浏览器安装。运行应用不需要这些工具。
